- Focus indicator: a clear, high-contrast lime outline on focused fields
  (`03-join-focusorder.png`).
- The whole registration → founding flow is completable with the keyboard alone.
- The Vintra advisor tip is exposed as a `status` live region (announced).
- Join-form and club-identity fields have proper visible labels and names.
- Colour swatch pressed state is exposed (`[pressed]`).
